## Description

## Example Parcel Type Vocabulary

This is an example of a jurisdiction specific set of parcel (spatial unit) type designations.

This is used to provide complete functional examples of the model using potentially multi-lingual code lists.

Note that a common terminology set could be defined by LADM or another shared profile.
